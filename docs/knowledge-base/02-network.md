# My computer cannot connect to the network

**Audience:** Employees · **Category:** Connectivity

## Try these steps

1. Check the network indicator and whether airplane mode is enabled.
2. For a wired office workstation, check that its network cable is securely connected. Do not disconnect production machinery, switches or unfamiliar cables.
3. For Wi-Fi, check that you selected the approved workplace network. Do not share its credentials.
4. Check whether the problem affects one application or all work websites.
5. Ask a nearby colleague whether they have the same problem. Record whether the issue affects one device or several.
6. If your organization requires a VPN for the affected resource, check its status using the approved client. Avoid changing adapter, DNS or firewall settings yourself.

## Contact IT when

Several users are affected, a production workstation is involved, or the checks do not restore service. Describe the business impact. Do not restart network infrastructure.

Include site, asset ID, wired/Wi-Fi, approximate start time, affected applications and whether nearby devices work. A diagnostic report's adapter state is only a link-state clue, not a complete connectivity test.
