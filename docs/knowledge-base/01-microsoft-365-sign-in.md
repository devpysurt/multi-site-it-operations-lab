# I cannot sign in to Microsoft 365

**Audience:** Employees · **Category:** Account access

## Before you start

Do not share your password, verification code or recovery code with anyone. IT should not need your current password to investigate a sign-in error.

## Try these steps

1. Check that you are using your work account, not a personal account with a similar address.
2. Open the usual company-approved Microsoft 365 sign-in page. Do not follow unexpected email links.
3. Read the error message and note its time. If safe to do so, take a screenshot without passwords, codes or private documents.
4. Check whether another approved work website opens. If several sites fail, follow the network guide.
5. If the browser selected the wrong account, use its account selection/sign-out controls and try your work account again. A private browser window can help identify a stale session; it does not fix account permissions.
6. Use the organization's approved password reset or MFA recovery process if needed. Stop after repeated failed attempts and contact IT.

## Contact IT when

Your account appears blocked, your MFA method is unavailable, access still fails, or the sign-in prompt looks suspicious. Report an unexpected MFA request promptly; do not approve it.

Include your site, device asset ID, application, exact error, time/timezone and whether other sites open. Use an approved support channel, not a public GitHub issue.
