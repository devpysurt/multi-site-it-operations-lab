# My computer is running slowly

**Audience:** Employees · **Category:** Performance

## Try these steps

1. Note when the slowdown started and which applications are affected.
2. Save your work and close unused applications and browser tabs.
3. Check whether a large download or an approved update is running. Let scheduled updates finish when practical.
4. Check free disk space in File Explorer. Do not delete system folders or shared business files to free space.
5. If workplace procedure permits it, restart after saving work and ensuring no critical process is running. Coordinate restarts of operational workstations with the responsible team.

## Contact IT when

The issue repeats, the computer freezes, storage is nearly full or there is an unusual warning. Do not install cleanup or tuning tools found online.

Include asset ID, affected apps, timing, whether restarting helped and the business impact. IT can use the workstation report to inspect storage and memory; the report is not a performance trace or malware scan.
